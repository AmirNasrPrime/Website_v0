# AXIOPHYS Science Gazette publishing

Research is served from `research.html`. Demo, Papers and PRIME-CAE Manuals are distinct categories selected by URL fragments (`#demo`, `#papers`, `#manuals`). Existing demonstrations remain at their original asset and article URLs.

## Add a paper

1. Obtain approval for public release and confirm authors, affiliations, date, abstract, results, references, and PDF rights.
2. Create a permanent HTML page and individual searchable PDF. Publish the full abstract in the HTML and link the PDF with a crawlable anchor.
3. Add the entry to the Papers panel in `research.html`. Use real metadata only: `citation_title`, one `citation_author` per author, `citation_publication_date`, `citation_pdf_url`, and `citation_doi` only if assigned. Add canonical and Open Graph metadata.
4. Add the permanent article URL to `sitemap.xml`, check links, keyboard access, PDF text search, and mobile layout. Record revisions on the article page.

## Add a manual

1. Confirm the documented PRIME-CAE version and public release approval.
2. Create a versioned permanent HTML page and, if appropriate, a downloadable PDF.
3. Add a crawlable entry to the Manuals panel in `research.html` with version and revision date. Update the sitemap and verify links.

## Video assets

The approved 2560×1280, 192-second silent master remains at its supplied source location outside Git. The site uses optimized 1920×960 and 960×480 H.264 derivatives plus a poster in `media/gazette/`. Preserve duration and composition when re-encoding. Source image provenance was supplied in the brief and has not been independently verified.
